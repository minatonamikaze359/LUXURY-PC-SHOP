## 📖 About The Project

**Luxury PC** is a modern e-commerce web application engineered specifically for high-end gaming hardware, custom rigs, and workstation components. Designed with a dark cyber/RGB aesthetic, it delivers a sleek UI coupled with a real-time **Custom PC Builder** that dynamically checks component compatibility (e.g., CPU sockets and Motherboards).

---

## ✨ Key Features

* 🖥️ **Custom PC Builder:** Step-by-step custom PC assembly tool.
* ⚡ **Real-Time Compatibility Checker:** Instant client-side validation for component sockets (e.g., LGA1700 vs AM5) to prevent hardware mismatch.
* 🔍 **Smart Product Search & Filters:** Filter rigs and hardware by price range, intended usage (Gaming vs. Workstation), or keyword search.
* 📸 **Interactive Product Showcase:** Product pages featuring photo galleries, specifications breakdown, and responsive cart updates.
* 🛡️ **Trust Badges & Neon Styling:** Cyberpunk/RGB-inspired dark mode UI with built-in trust badges (warranty, global shipping, 24/7 support).
* 📱 **Fully Responsive:** Optimized across desktop, tablet, and mobile displays.

🚀 Quick Start
Follow these simple steps to run the project locally.

Prerequisites
No external dependencies or node packages are required! All you need is a modern web browser.

Installation
Clone the repository:

Bash

Navigate to the project directory:

Bash
cd LUXURY-PC-SHOP
Open the project:
Simply double-click index.html or open it using VS Code Live Server to preview live changes.
